# Migrations

Migrations are generated by Prisma against the schema in `../schema.prisma`.
Run locally with:

```
npx prisma migrate dev
```

The first migration (`0001_bootstrap`) introduces the double-entry ledger,
partitioned lineups, and the real-money-ready user fields. See
`../../ARCHITECTURE.md` for the design rationale.

## Manual partitions

Prisma does not model Postgres `PARTITION BY` clauses. After running the
generated migration, apply the partitions in `sql/partitions.sql` — these
carve `ledger_entries` by month and `lineups` by contest-id hash so a hot
contest never blocks the primary.
